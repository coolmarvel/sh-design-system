목차
    01

    색 팔레트

    견본을 누르면 CSS 변수 이름이 복사됩니다. 테마를 바꾸면 바뀌는 값만 달라집니다.

    02

    타이포그래피

    돋움 12px 가 기준입니다. 크롬 글자는 14px 를 넘지 않고, 정수 크기만 씁니다.

    03

    간격·크기·모양

    반경 0, 모든 선 1px. 그림자는 메뉴·대화상자·종이에만 짧고 옅게.

    04

    부품

    위 도구모음의 "모든 상태 펼침"을 누르면 hover·눌림·포커스 상태를 한 번에 볼 수 있습니다.
